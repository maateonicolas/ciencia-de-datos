# Ciencias de Datos

Repositorio académico para el curso de Ciencias de Datos.

Autor: Mateo Diaz

Aquí se organizan laboratorios, proyectos, prácticas y material relacionado con la construcción de soluciones de datos reproducibles.

## Contenido del curso

Los principales temas trabajados son:

- Fundamentos de ciencias de datos.
- Python para análisis y procesamiento de datos.
- SQL y bases de datos.
- Contenedores con Docker.
- Infraestructura como código.
- Ingesta y procesamiento por lotes.
- Orquestación de workflows con Kestra.
- Almacenamiento en data warehouse y data lake.
- Calidad, limpieza y validación de datos.
- Modelado analítico y esquema estrella.
- Transformaciones con dbt.
- Construcción de pipelines ELT reproducibles.
- Buenas prácticas de Git y GitHub.
